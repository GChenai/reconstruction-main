# Reconstruction dataset

This repository contains the `dataset_mini` CSV dataset, organized into `FS/` and `TS/` directories.

The dataset contains 160 CSV files (2,880,616,739 bytes in total). CSV files are stored with Git LFS.

## Download

Install Git and Git LFS, then run:

```sh
git lfs install
git clone https://github.com/GChenai/reconstruction-main.git
cd reconstruction-main
git lfs pull
```

The data is available under `dataset_mini/` after download.
